Прочитай `data/news.json`. Выбери ровно 5 новостей и запиши их массивом
(те же объекты, без изменений полей) в `data/selected.json`.
Критерии: темы не повторяются; есть парадокс/контраст/невольно смешная деталь;
свежесть предпочтительнее. Стоп-лист (катастрофы, смерти, войны, болезни,
трагедии, дети, национальности/религии) — исключать без обсуждения.
В чат выведи только список выбранных id и по 5 слов обоснования.
